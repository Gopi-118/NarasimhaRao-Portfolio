# TAXORITHM Static Website

This project is a premium static website for TAXORITHM built with HTML5, CSS3 and vanilla JavaScript.

## Structure

- index.html – homepage
- about.html – firm overview and values
- services.html – service catalog
- knowledge-bank.html – tax and regulatory references
- calculators.html – working calculator demos
- updates.html – advisory and notification archive
- contact.html – contact form and location details
- services/ – dedicated service detail pages
- css/ – style layers
- js/ – site JavaScript modules
- assets/logo/ – branding assets

## Notes

- This is a static website intended for local browser use or static hosting.
- The contact form is a client-side prototype and uses WhatsApp as the functional enquiry alternative because there is no backend service configured.
- Tax and calculator assumptions are clearly labelled as sample and illustrative only.

## Run locally

From the project folder, start a local static server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in the browser.
